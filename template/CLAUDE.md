## File Reading Order
When starting any session in this repository, read in this order:
  1. SKILL.md          - understand this domain and operating rules
  2. CONTEXT.md        - understand the owner, goals, and principles
  3. CURRENT_STATE.md  - understand what is true right now
  4. PENDING.md        - understand what is waiting for approval

Only then proceed with the requested task.

## Operating Rules
  - Never modify a layer file without explicit approval from the owner
  - All proposals go to PENDING.md, never directly to layer files
  - If a task would affect multiple sub-domains, note all impacts in PENDING.md
  - If asked about something not in the current state, say so honestly
  - Generate learning content on request - write to notebooks/ folder

## What Requires Approval
  - Any change to CURRENT_STATE.md
  - Any new entry in DECISIONS.md
  - Any adoption or rejection recorded in EVALUATION.md
  - Any update to DOMAIN_MAP.md

## What Does Not Require Approval
  - Reading and explaining existing content
  - Generating learning modules to notebooks/
  - Writing proposals to PENDING.md
  - Running scripts (feed, generate, check)
