# Example: Home Garden Management Super Skill

This example shows how a Super Skill works for a personal,
non-technical domain. A home garden has seasons, decisions,
sub-domains, and drift - exactly like a software stack or
investment portfolio.

The same structure works for any personal domain:
dog training, fitness, nutrition, home renovation,
language learning, or anything else you care about.

## How to use this example
1. Review CONTEXT.md to see how a personal domain is defined
2. Review DOMAIN_MAP.md to see how sub-domains connect
3. Use these as reference when building your own Super Skill
