# Contributing to Super Skill

Super Skill is an open framework. Contributions are welcome.

## What to contribute

- New example domains (see examples/ for format)
- Improvements to template files
- Bug fixes in scripts
- Documentation clarity improvements

## What not to contribute

- Personal operational data of any kind
- Breaking changes to the layer structure without discussion
- Changes to the Iron Principle wording

## How to contribute

1. Fork the repository
2. Create a branch: git checkout -b fix/description
3. Make your changes
4. Verify: no personal data, Iron Principle intact, templates consistent
5. Open a pull request using the template

## Standards

- Use `--` (two hyphens) as a structural separator. Real em-dash characters (`—`) are also acceptable.
- All placeholder text in format: [DESCRIPTION IN CAPS]
- File headers follow the format in examples/stack-os/
- MIT License applies to all contributions
